# URL Shortener

A production-quality URL shortener: FastAPI (async, Python) backend, React + TypeScript frontend, PostgreSQL via Docker Compose.

## Features

- Shorten a URL with an optional custom alias, or get a random 7-character code
- Optional link expiration (`expires_at`)
- Click analytics: total clicks + per-day breakdown, backed by a `click_events` log
- Rate limiting on link creation (`10/minute` per IP by default)
- Structured JSON logging with per-request correlation IDs
- OpenAPI docs generated by FastAPI at `/docs` and `/redoc`

No authentication in this version — link creation is open/anonymous by design.

## Architecture

```
url-shortner/
├── docker-compose.yml     # Local Postgres only
├── backend/                # FastAPI service (Python)
│   └── src/app/
│       ├── api/            # Routers (thin: parse request, call service, return schema)
│       ├── services/       # Business logic (alias generation, expiry, analytics)
│       ├── repositories/   # Only layer that touches SQLAlchemy directly
│       ├── db/models/      # SQLAlchemy ORM models
│       ├── schemas/        # Pydantic request/response DTOs
│       └── core/           # Config, logging, exceptions, rate limiting
└── frontend/                # React + TypeScript (Vite)
    ├── src/                 # App, pages, components, hooks, API client
    └── e2e/                 # Playwright end-to-end tests
```

Backend and frontend run **natively** (uvicorn / vite) for a fast dev loop; only Postgres runs in Docker.

## Prerequisites

- Docker + Docker Compose
- Python 3.11+
- Node.js 20+ (repo was built/tested on Node 22.11 with Vite 5 pinned — see note below)

## Setup

### 1. Start Postgres

```bash
cp .env.example .env
docker compose up -d
docker compose ps   # wait for "healthy"
```

Postgres listens on **port 5433** on the host (not 5432), to avoid clashing with any local Postgres install. Adjust `POSTGRES_PORT` in `.env` if needed.

### 2. Backend

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
alembic upgrade head
uvicorn app.main:app --app-dir src --reload --port 8000
```

- API base: http://localhost:8000
- Interactive docs: http://localhost:8000/docs
- Health check: http://localhost:8000/healthz

### 3. Frontend

```bash
cd frontend
npm install
cp .env.example .env
npm run dev -- --port 5173
```

- App: http://localhost:5173

> **Gotcha:** the React app does **not** own short-link routes. A real short link like `http://localhost:8000/abc1234` must be opened against the **backend** (port 8000), not the Vite dev server (port 5173). The dashboard's links already point at the backend for this reason.

> **Node/Vite note:** `npm create vite@latest` currently scaffolds an experimental rolldown-based Vite 8 beta whose native binding fails to install under some npm/Node combinations (a known npm optional-dependencies bug). This project pins `vite@^5.4` (stable) and `@vitejs/plugin-react@^4` instead.

## Running Tests

### Backend — unit + integration

```bash
cd backend
source .venv/bin/activate
pytest tests/unit           # fast, no DB
pytest tests/integration    # spins up a throwaway Postgres via testcontainers + runs Alembic migrations
pytest tests/               # everything (28 tests)
```

Integration tests require Docker (they launch their own Postgres container independent of `docker-compose.yml`) but do **not** touch your dev database.

> **Flaky on macOS?** If integration tests fail with `Port mapping for container ... is not available`, that's testcontainers' Ryuk reaper hitting a Docker Desktop timing issue, not a code problem. Retry, or work around it with `TESTCONTAINERS_RYUK_DISABLED=true pytest tests/integration`.

### Frontend — end-to-end (Playwright)

Requires the full stack running (Postgres via Docker Compose, backend on :8000, frontend on :5173):

```bash
cd frontend
npm run test:e2e
```

## API Overview

| Method | Path | Description |
|---|---|---|
| POST | `/api/v1/links` | Create a short link (rate-limited) |
| GET | `/api/v1/links` | Paginated list of links |
| GET | `/api/v1/links/{short_code}` | Link detail |
| GET | `/api/v1/links/{short_code}/analytics` | Click analytics for a link |
| GET | `/{short_code}` | Redirect (302) to the original URL |
| GET | `/healthz` | Liveness/DB connectivity check |

Errors use a consistent envelope:

```json
{ "error": { "code": "ALIAS_TAKEN", "message": "...", "details": {}, "request_id": "..." } }
```

Full request/response schemas: http://localhost:8000/docs
